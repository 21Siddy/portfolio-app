Phase 01: Code Origin & Trigger

Local Development & Git Webhooks

Code is authored and validated locally. A single git push origin main executes an atomic push to GitHub. Instead of complex external CI runner bills, GitHub immediately broadcasts an encrypted webhook payload to my self-hosted deployment daemon.

Django 5.0 Git Hooks HMAC SHA-256 Webhook
Phase 02: Ingress & Perimeter Security

Cloudflare Zero Trust Tunnel

The domain oldisserving.live connects without opening any inbound ports on my residential router. A background Cloudflare Tunnel daemon (cloudflared) establishes four redundant, persistent outbound TCP/QUIC connections to Cloudflare edge data centers. All inbound web requests pass through Cloudflare DDoS filtering and WAF rules before flowing through this private pipe.

Argo Smart Routing Zero Inbound Open Ports TLS Termination DDoS Shield
Phase 03: Self-Hosted PaaS Automation

Coolify Engine & Container Orchestration

Coolify runs locally as an open-source alternative to Heroku or Render. Upon receiving the GitHub webhook, it pulls the repository diff, analyzes the dependency tree, and builds a fresh, reproducible Nixpacks container image. Traefik automatically routes traffic to the newly spun container with zero-downtime rolling deploys.

Coolify PaaS Docker Engine Nixpacks Traefik Reverse Proxy
Phase 04: The Physical Host

Lenovo Legion Y540 Bare-Metal Server

The final destination. An old gaming laptop repurposed into a headless Linux server running Ubuntu 24.04 LTS on my desk in Paderborn. It handles the Django application process, persistent PostgreSQL database, and reverse proxy 24 hours a day with complete local data sovereignty.

Technical Overview & Design Decisions

01. Bare-Metal Host & Efficiency

Repurposed Hardware

Running on a headless Lenovo laptop with Ubuntu 24.04 provides a quiet, energy-efficient server drawing under 20W at idle. The integrated battery acts as a natural mini-UPS, buffering momentary power drops and preventing database corruption without extra rack hardware.

02. Zero-Inbound Network Security

Zero Open Ports

Residential broadband uses dynamic IPs behind consumer NAT. Rather than opening firewall ports or port-forwarding, the host maintains an outbound-only encrypted tunnel to Cloudflare. The local firewall drops all unsolicited inbound traffic. Admin interfaces bind strictly to localhost and are never exposed publicly.

03. Automated CI/CD & Storage Resilience

Git Automation & Persistence

Commits pushed to GitHub dispatch encrypted webhooks to the local deployment engine, which compiles reproducible container images and signals the reverse proxy to swap traffic with zero downtime. Relational data is mapped to persistent host volumes, separating app updates from database storage.
